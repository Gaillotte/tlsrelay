# vcpkg overlay ports

## openssl (3.5.x, long-term support branch)

On Windows, tlsrelay ships the **OpenSSL 3.5 LTS** branch (supported until
April 2030). The vcpkg catalog moved to the 3.6 branch after 3.5.4;
this port reuses the official vcpkg recipe (`ports/openssl`, with its
patches unchanged) while pinning it to the latest 3.5 release.

Difference from the vcpkg recipe: the sources come from the **official
release archive** published by the OpenSSL project
(`releases/download/openssl-X.Y.Z/openssl-X.Y.Z.tar.gz`), checked against its
SHA-512 hash, instead of the archive generated by GitHub.

### Moving to a new 3.5.x release

1. Update `version` in `openssl/vcpkg.json`.
2. Download `openssl-X.Y.Z.tar.gz` and `openssl-X.Y.Z.tar.gz.sha256` from
   the release page; check the published SHA-256 hash.
3. Copy the new SHA-512 hash (`sha512sum`) into
   `openssl/portfile.cmake`.
4. Check that the patches still apply (`git apply --check`).

The Windows CI fails if the bundled version is not a 3.5.x.
